Promotion Assessment

📊 Connect to Google Sheets

Push your assessment data directly to a Google Sheet. One-time setup required.

Setup steps (one time):
  1. Go to console.cloud.google.com → create or select a project
  2. Enable Google Sheets API under APIs & Services
  3. Create OAuth 2.0 Credentials → Web application
  4. Add http://localhost:8080 to Authorized JavaScript Origins
  5. Copy the Client ID into the field below
  6. Create a blank Google Sheet and copy its ID from the URL
Run with: python3 -m http.server 8080 then open http://localhost:8080
